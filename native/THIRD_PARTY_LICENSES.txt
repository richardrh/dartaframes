Third-party dependency license inventory
=========================================

The native library is built from the locked dependency graph in Cargo.lock.
All direct and transitive Rust dependencies are redistributed under the
license terms declared by their upstream packages. The dependency graph is
limited to permissive licenses (Apache-2.0, MIT, BSD-2-Clause, BSD-3-Clause,
ISC, Zlib, Unicode-3.0, and equivalent dual-license expressions).

Dependency sources and exact license declarations are pinned by Cargo.lock and
are reviewed as part of the native release workflow. This file is included in
every native asset so the release is self-contained; upstream license texts
remain available from the corresponding crates.io package sources.
